# Bubloo Scientist Academy

A website written from scratch in HTML, CSS, and JavaScript, focused on course registration.

## Open the site

Open `dist/index.html` in a browser. For a local server, run `python -m http.server 4173 --directory dist` from this folder, then visit http://localhost:4173.

## Included

- Original logo downloaded from the existing academy website, unchanged.
- Navy and cyan design with responsive layouts.
- Registration buttons leading to the embedded real Google Form supplied by the owner: https://forms.gle/HZchBnCkmf3WFBJi6.
- Direct form links as a fallback.
- Seven expandable curriculum previews, prompt example tabs, a copy button, and FAQs.
- Existing course title, launch fee, and course structure retained from the reference website.

The Google Form handles submissions. No replacement form, placeholder, custom submission service, or payment integration is included. Google Forms controls the embedded form's content, permissions, and confirmation message. No test registration was submitted.

The course workbook link points to the existing website. Google Fonts requires internet access; system fonts are used as a fallback.
